# MicroMachines

Et lille browser-bilspil i ånden fra det gamle *Micro Machines*: to legetøjsbiler
der drifter rundt på et køkkenbord. To spillere på ét tastatur, splitscreen,
én bane, ingen computerstyrede modstandere.

Bygget med Three.js, Vite og TypeScript.

## Kom i gang

```bash
npm install
npm run dev
```

Åbn http://localhost:5173

## Styring

| | Speeder | Bremse/bak | Venstre | Højre | Håndbremse |
|---|---|---|---|---|---|
| Spiller 1 | `W` | `S` | `A` | `D` | venstre `Shift` |
| Spiller 2 | `↑` | `↓` | `←` | `→` | højre `Shift` |

## Bilerne

**Soba Supreme** og **Porcini 911** er opdigtede legetøjsbiler. Enhver lighed
med rigtige biler er ren karosseri-poesi.
